# A useful local project first

Agent Zero Trust is MIT-licensed software created by Rafael (Ralph) Peña, with
credit to contributors and upstream maintainers. Local intake, local policy,
essential future execution controls and stop mechanisms, inspection, evidence
export and public benchmark tooling should remain useful without an account.
No telemetry, activation keys, artificial agent limits or mandatory cloud service
are introduced by this milestone.

The local policy schema and evidence formats are the integration seams.
Optional future organization services could distribute reviewed policies,
collect voluntary exports, support approval workflows and retention, or operate
managed execution. Local enforcement must not depend on their availability.
Those services should meet demonstrated organizational needs. They are not
implemented features, pricing commitments, compliance claims or certification.

Contributors retain the project's existing contribution terms. This document
does not change the license, create a CLA/DCO obligation, or assert new rights.
